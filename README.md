# Blind Typing — Offline Mirror

Полная автономная копия сайта blindtyping.com: 5 языков (en, ru, fr, de, es),
все страницы, уроки, тест, практика, настройки, лидерборд, данные, чанки,
шрифты и картинки. Работает без интернета.

> **Это не официальный сайт.** Это архивная копия, сделанная для офлайн-использования.
> Оригинал: https://blindtyping.com/

## Запуск локально

    cd blindtyping-offline-mirror
    python -m http.server 8080

Открыть http://localhost:8080/

Не открывайте `index.html` двойным кликом (file://) — браузер блокирует
загрузку JS-чанков. Нужен локальный HTTP-сервер.

## Что изменилось относительно оригинала

- Сетевые запросы бэкенда отключены и заменены на `localStorage`.
  Настройки (тема, звуки, режимы, скрытие рук и т.д.) сохраняются в браузере
  и не сбрасываются после перезапуска.
- Добавлены локальные данные: `languages/*.json`, `languages/practice/*`,
  `keymaps/*.json`, `lessons/*.json`, темы, уведомления, чанки.
- Маршруты уроков `/lessons/qwerty/1/0`, языковые версии и локализованные `docs`.
- Локальные заглушки API вместо `/backend/api/*`.
- `404.html` (SPA fallback), `.nojekyll` (для GitHub Pages).

## Деплой

Статический сайт, без сборки. Залить папку в ветку `main` — Pages уже настроен.
Публиковать в корень ветки. `CNAME` не используется.

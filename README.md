# Blind Typing — локальная офлайн-копия (100%)

Полное зеркало https://blindtyping.com/: 5 языков (en, ru, fr, de, es),
все страницы, уроки, тренажёр, тест, практика, настройки, лидерборд,
JSON-данные, JS-чанки, CSS, шрифты и картинки. Работает полностью офлайн.

## Запуск

Двойной клик по `start_blindtyping.bat` внутри папки, затем открыть
http://localhost:8080/ — либо вручную:

    cd blindtyping_site
    python -m http.server 8080

Важно: не открывать index.html двойным кликом (file://) — браузер блокирует
загрузку JS-чанков. Нужен локальный HTTP-сервер.

## Что сделано

- Все сетевые запросы бэкенда (fetch/axios/XHR, /backend/api/*) отключены
  и заменены локальным хранилищем. Настройки, тема, звуки, режимы тренировок,
  скрытие рук и т.д. сохраняются в localStorage и не сбрасываются после
  перезапуска страницы или сервера.
- Добавлены локальные данные: languages/*.json, languages/practice/*,
  keymaps/*.json, lessons/*.json, themes, уведомления, чанки.
- Маршруты уроков /lessons/qwerty/1/0 и языковые версии /ru, /en, /fr, /de, /es
  работают без 404 и CORS.
- Локальные заглушки API: /backend/api/users/me, /backend/api/leaderboard,
  username-availability.
